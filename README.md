# PDF Summarizer Agent

Cloud-trained, locally-running agent that generates a summary of an uploaded English-language PDF.

Same architecture philosophy as [AI-Software-Engineer](https://github.com/snoussimakrem/AI-Software-Engineer-Cloud-Trained-Locally-Running-Coding-Agent):
the local machine is a control center only (orchestration, storage metadata, CLI) — all
LLM training/inference runs on free cloud GPU platforms (Colab).

## Status

Just started — architecture and scope still being defined.
